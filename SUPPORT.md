# Getting help

| You want to | Go to |
|---|---|
| Set up the MCP server in your client | [Documentation](https://help.repeatpost.com/integrations/mcp-server) |
| Read about the MCP server | [www.repeatpost.com/mcp](https://www.repeatpost.com/mcp) |
| Learn about RepeatPost | [www.repeatpost.com](https://www.repeatpost.com) |
| Get help with your account, channels, billing or a connection | [support@repeatpost.com](mailto:support@repeatpost.com) |
| Report a bug or request a tool | [GitHub issues](https://github.com/repeatpost/repeatpost-mcp/issues) |
| Report a security vulnerability | [SECURITY.md](SECURITY.md) |

Many common problems are covered in the README's [Troubleshooting](README.md#troubleshooting) section.

## What to include

- the AI client you use, such as Claude, Claude Code, Cursor or VS Code
- the tool involved, if you know it, such as `schedulePost`
- the date, time and time zone when it happened
- the exact error message

Never include access tokens, refresh tokens, passwords or API keys. GitHub issues are public.
